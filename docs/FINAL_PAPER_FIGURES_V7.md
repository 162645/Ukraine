# Final paper figures v6/v7

The server-side redraw scripts for the current paper figures are:

- `scripts/plot_figures_v6.py`: strict Figure 2--5 redraw from the frozen v5 result.
- `scripts/plot_figures_v7.py`: layout-only revision based on `final_paper_compact_v6`; Figure 2 and Figure 4 are copied byte-for-byte, while only the Figure 3 inset and Figure 5 spacing are changed.

The scripts are intended to run on the configured analysis server. Figure 1 is supplied separately and is intentionally not generated by these scripts.
