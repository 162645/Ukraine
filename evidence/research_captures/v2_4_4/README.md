# Research captures versus canonical evidence

These files record facts re-verified from live official pages during package preparation. They are **not** exact server response bytes and do **not** satisfy the final immutable-evidence gate.

For submission readiness:
- official web pages must be archived locally with `scripts/archive_public_sources.py`;
- Telegram sources must additionally be ingested from a Telegram Desktop JSON export;
- hashes must be verified with `scripts/verify_evidence_archive.py`.

The verifier is intentionally not weakened by the presence of these research captures.
